# Ozon MCP

[MCP](https://modelcontextprotocol.io/)-сервер для **личного кабинета покупателя**
[ozon.ru](https://www.ozon.ru/). Даёт языковой модели доступ к заказам, истории
покупок, корзине, избранному, подборкам и вишлистам, карточкам товаров
(варианты, фото, отзывы, описания, характеристики), поиску по каталогу с
фильтрами, а также к балансу Ozon Карты и баллам — через внутренний
`composer-api`.

> В отличие от парсеров, которые умеют только анонимный каталог, этот сервер
> работает **под вашей авторизованной сессией**: он читает личные данные
> (заказы, покупки, корзину, баланс) и — если это явно включено — меняет
> корзину и избранное.

## Как это работает

Антибот Variti блокирует не-браузерные клиенты, поэтому сессия **один раз**
поднимается через настоящий headed-Chromium под Xvfb: он проходит проверку, а
из него забираются cookies и набор client-hint заголовков. Дальше все чтения и
записи идут обычным HTTP через
[`curl_cffi`](https://github.com/lexiforest/curl_cffi) (имперсонация TLS-отпечатка
Chrome) — браузер на каждый вызов больше не нужен. Он остаётся только для
обновления токенов и нескольких чтений, которые Ozon рисует на клиенте.

Требования: запуск с **российского IP** (Ozon режет датацентры и VPN) и заранее
сохранённая авторизованная сессия (`state.json`).

## Инструменты

| Инструмент | Что делает |
|---|---|
| `list_orders` | Заказы (активные / завершённые из архива / все): статус, срок, дата, суммы, миниатюры |
| `orders_by_date` | Завершённые заказы за диапазон дат (ISO) |
| `order_products` | Товары одного заказа (заказ → карточка товара) |
| `list_purchases` | Полная история покупок (сортировка по дате / цене) |
| `search_purchases` | Быстрый серверный поиск внутри покупок |
| `search` | Поиск по витрине с сортировкой и фильтрами-фасетами |
| `get_search_filters` | Доступные фасеты (категория / бренд / диапазон цены / …) для запроса |
| `browse_category` | Товары категории по слагу |
| `product_details` | Название, цена, варианты (цвет/размер), характеристики, фото |
| `get_photos` | Все фотографии товара |
| `get_reviews` | Отзывы с оценкой, текстом, датами и фото |
| `get_characteristics` | Характеристики товара (имя/значение) |
| `get_description` | Текст описания товара + картинки из него |
| `delivery_estimate` | Срок доставки товара |
| `find_cheaper` | Найти такой же / похожий товар дешевле |
| `get_cart` | Содержимое корзины с количествами |
| `add_to_cart` / `remove_from_cart` / `set_cart_quantity` | Изменение корзины (под флагом) |
| `list_favorites` | Избранное в виде плиток товаров |
| `favorites_price_snapshot` / `check_favorite_price_drops` | Мониторинг цен в избранном |
| `list_collections` / `list_wishlists` | Подборки и вишлисты |
| `get_lists` | Подборки и вишлисты вместе с их id |
| `add_to_list` / `remove_from_list` | Состав подборок/вишлистов (под флагом) |
| `set_favorite` | Добавить/убрать из избранного (под флагом) |
| `list_returns` | Возвраты покупателя |
| `get_finances` | Баланс Ozon Карты и общая сумма баллов |
| `get_points` | Баллы по типам + сгорающие + бонусы по магазинам |

Изменяющие инструменты **по умолчанию отключены** — включаются переменной
`OZON_ENABLE_WRITES=1`.

## Сессия (разовый вход)

Вход в Ozon идёт через email и 2FA (пуш или флеш-звонок), поэтому это **разовая
ручная процедура**, результат которой — файл `state.json` (Playwright storage
state). Путь к нему задаётся через `OZON_STATE`. Дальше сессия обновляется сама;
полный повторный вход нужен только когда истечёт сам refresh-токен.

## Настройка

| Переменная | По умолчанию | Что задаёт |
|---|---|---|
| `OZON_STATE` | `/data/state.json` | Путь к сохранённой авторизованной сессии |
| `OZON_IMPERSONATE` | `chrome124` | Профиль TLS-имперсонации curl_cffi |
| `OZON_ENABLE_WRITES` | `0` | Разрешить изменение корзины/избранного/подборок |
| `OZON_MONITOR_STORE` | `/data/price_history.json` | Файл истории цен избранного |

См. `env.example`.

## Запуск

Docker (headed-Chromium и Xvfb уже внутри образа):

```bash
docker build -t ozon-mcp .
docker run -i --rm --shm-size=1g -v "$PWD/data:/data" ozon-mcp
```

Локально через [uv](https://docs.astral.sh/uv/):

```bash
uv sync
uv run playwright install --with-deps chromium
uv run python -m ozon_mcp   # для бутстрапа нужен дисплей или Xvfb
```
